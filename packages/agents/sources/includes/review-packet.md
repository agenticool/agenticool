Review packet: `review_mode=pre_pr|requested`, repo, the URL of every issue that supplies criteria (or `none` when the criteria come from the request), the acceptance criteria for this layer, the remote ref (a branch, or `pull/<N>/head` for a requested PR review), the immediate base SHA, the pushed head SHA, a worktree path that already has the objects, and the reviewer's own resolved `Policy:` line are required. It also carries the accepted decisions, a changed-file summary, the relevant validation results, and verified prerequisites when applicable, each with an explicit `none` or unavailable result, plus the remaining fields from `.agents/review.md`. A re-review packet adds the previous round's base and head SHAs and its complete report; `.agents/review.md` sets its scope.
